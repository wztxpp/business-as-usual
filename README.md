# 明天照常 · Tomorrow as Usual

一个完整、无声的中文职场叙事探索游戏。当前内容为 **V3**：三章、九项有前后依赖的工作任务、八位角色、现场线索、顺序/多选任务、分阶段对话、100 分任务评分和本地自动存档。

这是独立的 Vue 3 + Vite 项目，无需服务器数据库、账号、API Key 或环境变量。不是其他游戏仓库的分支。

## Windows 快速开始

### 1. 安装与获取源码

- 安装 **Node.js 24**（自带 npm）；最低支持 Node.js 22.12。开发验证环境为 Node.js 24.22.1。
- 使用 Git 克隆本仓库，或在 GitHub 点 **Code → Download ZIP** 后解压。
- 在含有 `package.json` 的项目文件夹中打开终端。资源管理器地址栏输入 `cmd` 再回车，即可在该目录打开命令提示符。

检查安装：

```bat
node --version
npm --version
```

### 2. 安装依赖并运行

```bat
npm ci
npm run dev
```

浏览器打开：**http://127.0.0.1:5181/**

保留终端窗口；结束运行按 **Ctrl+C**。修改 `src` 后通常会自动刷新。

- 开发和预览端口都固定为 **5181**，启用 `strictPort`，占用时直接报错，不会悄悄切到其他端口。
- 预览和开发不能同时占用 5181。先在正在运行的窗口按 Ctrl+C，再启动另一个命令。
- 若 PowerShell 提示不能运行 `npm.ps1`，可使用命令提示符，或把命令中的 `npm` 写为 `npm.cmd`。无需更改系统执行策略。
- 初次 `npm ci` 需要联网下载依赖。安装成功后，本地游戏运行不需要外部服务；所有人像和场景均在仓库中。

### 3. 测试、构建与生产预览

```bat
npm test
npm run build
npm run preview
```

预览地址同样为 **http://127.0.0.1:5181/**。构建产物在 `dist/`。请通过开发或预览服务器打开，不要双击 `index.html`。

也可一次检查测试和构建：

```bat
npm run check
```

## 存档与评分

- 进度自动保存在当前浏览器当前地址的 localStorage，键为 `tomorrow-as-usual:v2`。V3 延续此键以兼容旧进度。
- 正确完成任务后直接进入同事复核；证据选择、剧情对话和章节决定仍由玩家操作。
- 初始 100 分。每个不同的有效错误任务答案扣 4 分；重复提交同一错误、未完成的排序、闲聊、探索、时间和剧情选择不扣分。
- 清空排序只清除尚未提交的选择，不影响存档和分数。
- 游戏内“重新开始”会先确认，再清除本游戏当前地址的存档。请勿在需要保留进度时确认重开。
- 不同浏览器、端口、`localhost` 与 `127.0.0.1`、线上地址之间**不共享**存档。删除浏览器站点数据也会删除进度；没有云端备份。

## 目录说明

```text
src/
  main.js           Vue 界面、对话、任务提交和可访问性交互
  story.js          八位角色、三章九任务、线索、闲聊和结局
  engine.js         任务依赖、答案判断、评分、存档验证
  transitions.js    日期/章节/阶段转场与恢复逻辑
  style.css         桌面/窄屏样式与减少动态效果支持
public/art/         8 张本地 PNG 人像、3 张 SVG 场景
tests/             自动化回归测试（修改剧情和规则后请运行）
index.html          页面入口
vite.config.js      开发及预览地址、5181 严格端口
package-lock.json   固定依赖解析结果，配合 npm ci
```

## 继续开发

1. 修改角色/任务文本优先编辑 `src/story.js`；修改评分或状态转换编辑 `src/engine.js`。
2. 保留已有角色、任务、线索和选项的稳定 ID，以免破坏旧存档。
3. `work.answer` 使用从 0 开始的选项索引；界面的 A–E 是固定标识，右侧“第几步”是玩家选择的顺序。
4. 替换图片时沿用 `public/art/` 文件名，或同步调整界面引用。图片来源与映射见 [ASSETS.md](ASSETS.md)。
5. 提交前执行 `npm run check`。测试含完整路线、前置条件、错答去重、存档迁移、转场恢复和复核流程。

### 版本边界

本次源码导出保留 V3 剧情、任务、评分与存档行为；补充跨平台运行配置和说明。字体使用系统本地字体回退，不再请求在线字体服务。不同电脑的字形可能略有差异。

仓库不包含依赖安装目录、构建产物、临时测试页面、凭据或线上托管元数据。本次上传**不会自动发布网站**；没有部署工作流，也不修改原有线上版本。若以后要部署到 GitHub Pages 的 `/仓库名/` 子路径，需要先适配 Vite `base` 和图片路径；当前支持本地运行和站点根路径部署。
